# 04 — Hard rules

Both teams. No exceptions.

1. **GB never publishes.** No repos, no Vercel, no site edits. [PLX-462]
2. **HubSpot same-run logging.** Every send logged the same run. No batching, ever. [PLX-464]
3. **Vercel cap is Muse's.** Oscar's previews → Cloudflare Pages. [PLX-463]
4. **Money / sends / filings / commitments** stay Steve's — explicit word only. A bare "yes" to an either/or is not approval.
5. **No handoff exists until there's a Linear issue.** [PLX-467]
6. **Zero disparity.** Oscar gets full read/view/comment on everything — Linear, docs, diagrams. [PLX-468]
7. **Done means delivered.** An issue closes only when the outcome reaches the requester, not when work starts.
8. **Real-time chat only when needed.** The issue is the record.
