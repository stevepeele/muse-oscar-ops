## Triage flow

1. **Prospect identified** (Oscar) → enriched, scored
2. **Needs a preview?** → Oscar sends one-line build request → Muse builds & ships → live link back
3. **Outreach** (Oscar) → every send logged to HubSpot same run
4. **Reply / meeting** → Oscar runs it, HubSpot stage moves
5. **Decision needed** → Linear issue labeled `decision`, options + recommendation → Steve
