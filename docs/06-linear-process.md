# 06 — Linear process

**Project:** [P-PLX-33 "Muse × Oscar Ops"](https://linear.app/plxio/project/muse-oscar-ops-27f36aa6a48f) — the book of record for every handoff. [PLX-467]

## The flow

| Step | Who | Rule |
|---|---|---|
| **Create** | Either | No handoff exists until there's an issue. Title names the ask. |
| **Assign** | Either | Build requests → Muse. Pipeline/forensics → Oscar. Assignee = the one doing the work. |
| **Delegate** | Either | Whoever needs work from the other creates the issue, assigns it, sets the due date. |
| **Decide** | Steve | Issues labeled `decision` carry options + recommendation. Nothing moves without his word. |
| **Close** | Owner | → Done only when the outcome is delivered, not when work starts. |

## Mechanics

- Statuses: Backlog → In Progress → Done.
- Time-sensitive handoffs carry due dates.
- Comments on the issue replace side-channel DMs.
- Every issue update is mirrored to Oscar in chat + shared docs — zero disparity. [PLX-468]
